## Scenario
Veronica the customer service agent sometimes makes a few “oopsies.” She sometimes prematurely closes a case and then creates a new one to track the current case resulting in inaccurate metrics.

Objective: Configure the ability for agents to re-open cases if they are in "Resolved" state via a declarative action
