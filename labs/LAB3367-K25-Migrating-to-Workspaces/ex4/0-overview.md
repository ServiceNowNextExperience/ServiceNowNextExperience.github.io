## Scenario
The Page Collection tab allows Vicki, a customer service agent, to quickly access relevant information - reducing the time needed to resolve a case and finding the details all in one place.

**Objective**: Create two pages on the workspace sidebar tab so agents can quickly view applicable information in one place

- View all configured recommended actions for the current cases
    

- View other recommended cases that are related to the same Account
    

Note: Full configuration steps for activating Recommended Actions are covered in next exercise. This excise only covers how to add the component to the page.
