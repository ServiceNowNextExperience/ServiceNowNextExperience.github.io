## Overview
In this activity, you will create 2 pages for the existing OOTB CSM default page record post-tabs

## Instructions
1. Navigate to UI Builder  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FZ9V3mQquHocqMFIvzyC2%252Fimage.png%3Falt%3Dmedia%26token%3D5136a8e0-0ac8-4919-b296-4c3fdc5a1c33)

    Or if you are already in UI builder, go to left top top most corner and click on UI Builder icon which takes you to the homepage of UI builder  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FlypPJpWuTWbPgmwsdK10%252FScreenshot%25202025-04-21%2520at%25208.41.56%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D1571f208-66b1-43de-bded-5a69d2085dfb)

2. Click on Page Collections  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252F6CpUgCZIe2rd13ZtKelg%252FScreenshot%25202025-04-21%2520at%25208.42.36%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D0855ba2d-731e-4d22-bbc5-c84bf1b103a5)

3. Type ‘CSM’ in the search box and click on "CSM default record post-tabs"  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FOLF3LHDldjsQNC0RwgHh%252FScreenshot%25202025-04-21%2520at%25208.42.55%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Dbac8b56c-7b34-4d7f-9eb9-b7ecd8bcd4ca)

    Note: post tabs refer to the related lists that are below the main record header including related tasks, attachments, etc

4. Click on the + icon to create a new page.  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FMxuJzN6xE3LI3UXCldCz%252FScreenshot%25202025-04-21%2520at%25208.43.17%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D195e16de-09d8-497d-a254-f6bf0f3fba33)

5. Provide below details and click on continue.  
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FtUGqQOC5KNsxJKzG7ldx%252FScreenshot%25202025-04-21%2520at%25208.43.38%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D311db1ca-e6fc-41d0-82d6-35eeffb68e86)

6. Provide name and click on continue.
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252F42iy63QhLzkmSSAnqn2g%252FScreenshot%25202025-04-21%2520at%25208.44.07%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D8ae243c8-4fd4-413c-b1de-475c2064e612)

7. Select Build responsive and click Create.

8. **K25 CSM Page 1** is created.

9. Follow the same similar steps to create **K25 CSM Page 2**.

10. We have created 2 new pages.

11. Click on **K25 CSM Page 2** to add an icon in next activity.
