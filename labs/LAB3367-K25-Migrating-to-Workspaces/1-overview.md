Welcome to the Migrating to Configurable Workspaces Lab! This hands-on lab is made up of five exercises designed to help builders, system administrators, and implementation specialists gain practical experience creating and configuring pages in UI Builder. Each exercise builds on key concepts like page structure, data sources, component binding, and client-side actions, providing a structured path from exploration to advanced troubleshooting. Please note: Exercise 4 (building the Page Collection) must be completed before beginning Exercise 5 (working with Recommended Actions), as it provides the foundational page structure needed for the final exercise.

Workspace areas that this lab will cover:

- List and Forms
- Dashboard on L1 menu
- Declarative Action
- Sidebar tab Page Collection
- Sidebar tab Recommended Actions
    

### Prerequisites

- **ServiceNow Version:** Yokohama
    

- **Store Apps and Plugins:**
    
    - CSM and FSM Configurable Workspace Foundation version 25.0.14
    
    - Customer Service Management Demo Data (com.snc.customerservice.demo)
    
    - UI Builder Version: 27.2.49
        - ** UI Builder is now a store application. If you see things different from how they are presented in the lab, check the application manager to see if you've got a pending update.
