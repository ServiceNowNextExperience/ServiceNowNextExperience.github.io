## Scenario
Vicki, a CSM agent, spends too much time digging through KB articles than resolving cases. One day, you, a gifted system admin realize that Recommended Actions could be her AI powered sidekick.

Objective: Configure the ability for agents to view recommended actions to create a case task and view relevant KB articles all in one place.

Prerequisites: Complete exercise 3 (Configure Sidebar Tab page Collection) to test your recommended Action changes for this exercise
