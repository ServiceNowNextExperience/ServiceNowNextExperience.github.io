## Overview
In this activity, you will modify a Form Layout to add 2 new fields for the CSM case record

## Instructions
Note: ServiceNow best practices for modifying (ie edit/create/update) a form layout is to use the **Form Builder**. For this activity we are going to add two fields using the Form Layout instead of Form Builder to demonstrate how straight forward it is for an admin to make form updates

1. In CSM workspace, go to All cases and select any case by clicking the CS number

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FFcOsRKLCVVStdXF6wcMV%252Fimage.png%3Falt%3Dmedia%26token%3Dc39ececd-9cb7-411f-9ff7-aaf06764fcab)

2. On the top right corner, click on the user profile and navigate to the Configure page -> Form Layout

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FFQuDVLVQv9ALCKOVotFb%252FScreenshot%25202025-04-21%2520at%25208.32.07%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Dfab64911-63d8-44b7-adb5-c722229abbc3)

3. Select **Edit this section** in CSM workspace. Note: a pop up for modifying this list with **Form Builder** may appear - disregard this by x'ing out of the window

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FfvNfbtim74jQ7iMfVycD%252FScreenshot%25202025-04-21%2520at%25208.32.45%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D9921ced7-7c9d-4414-a2d3-1bbc754f26dc)

4. Select **Category** and add to the selected section and move it up to just below **Assigned to**

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FtMEbAFEPmVGxmaaJ4EL4%252FScreenshot%25202025-04-21%2520at%25208.33.26%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D34c4ae43-7a76-4e2f-8806-8e5429aaf404)

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FYEScVshKUm3Ze7MKX1Mz%252FScreenshot%25202025-04-21%2520at%25208.33.50%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D23ad9453-74ed-4ca5-a9bd-d117a3092ef9)

5. Add Subcategory field and move below to Category field. Click Save

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FeB1gO8mlu8Fwf6yNqfUt%252FScreenshot%25202025-04-21%2520at%25208.34.29%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Dbea5d67c-4d77-4046-908c-9eaee2d12138)

6. Lets test the results. Navigate back to the CSM/FSM Workspace and check out your changes. Confirm everything looks fine. You might need to hard refresh your browser tab to see the changes take effect

7. Click on a case record and refresh the page to see your changes

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FeZEAD3RWgVDhT2SGSCOM%252FScreenshot%25202025-04-21%2520at%25208.36.08%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D98f671ba-f2ae-489f-beba-74a85fb71fe4)

8. Click on new List and see the results with critical cases with assigned group
