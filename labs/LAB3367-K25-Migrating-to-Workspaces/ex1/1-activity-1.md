## Overview

In this activity, you will navigate to the correct list configuration for the  CSM/FSM Configurable Workspace list page and add a new list category ‘My Top Priority!’ to the List view.

## Instructions
1. Select the “Workspaces” menu and select CSM/FSM Configurable Workspace. On the left sidebar menu, click on the list icon. Notice the case category with four default pre-set lists of "My Cases," "My Open," "Unassigned for my groups," and "All."

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252Fio6P3lUxJIFnip8acKEe%252FScreenshot%25202025-04-21%2520at%25208.07.39%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D457931ce-8136-4a65-b6a6-cc92e3cab59d)


2. Go to All -> UI Builder

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FvIFB9vhvRJPLyOqYq69w%252Fimage.png%3Falt%3Dmedia%26token%3Dd4040482-7e29-4e6a-a780-3d7864244aec)


3. Change the scope - At the top right of the page, click the drop-down arrow and select **CSM and FSM Configurable Workspace Foundation**

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FMBVBc6L3OorZ75uE57qL%252FScreenshot%25202025-04-21%2520at%25208.09.42%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D8a4d8cc8-a874-4889-9f2b-612a557affb0)


4. Once UI Builder loads. On top banner click on ‘Experiences’ and search for CSM/FSM Configurable Workspace

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FvkUqZLL40a6iFljAQRkK%252FScreenshot%25202025-04-21%2520at%25208.11.35%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Daeccc979-2252-4858-a439-4a74e38dfe51)


5. Scroll down to find the “List” page and select the “List Default” and click on **Editor**

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FKBXGjJESia6Rf1fhQqow%252FScreenshot%25202025-04-21%2520at%25208.12.33%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D419ca057-cbf2-43ac-a955-8edc8b93227f)


6. On the left side is the Content Panel

   - Select the **List Nav** component from the content tree
   - On right side bottom click on ‘Configuration’
       

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252FnmtI3VcrPolBm6g3NUmp%252FScreenshot%25202025-04-21%2520at%25208.13.36%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D4e950df6-0ded-469f-be60-bcdb9d8e05e2)


7. Select ‘CSM/FSM Configurable Workspace List Menu’

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252Fduc68xfjaXcWCnw8yWzI%252FScreenshot%25202025-04-21%2520at%25208.16.20%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Df8b513a9-c96f-43b7-83b0-2df5b5bfb151)


8. In the UX List Categories tab click on **New**

    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252Fu7fRr5uVAiekSC7TGzDs%252FScreenshot%25202025-04-21%2520at%25208.16.55%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D7f81a56c-78dc-4252-8e80-b14e624c1347)


9. Provide details as below:
   - Title = My Top Priority
   - Order = - 10 (to show this category on top of the list)
   - Description = My Top Priority cases


    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252F1J8KUaWzBaQLEPGCl1gp%252FScreenshot%25202025-04-21%2520at%25208.18.17%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3D66d8d304-b82c-475e-b8a8-44a8c477fd3b)


10.  You will see new category 'My Top Priority' on top of the list under UX List Categories tab.
    ![](https://www.gitbook.com/cdn-cgi/image/dpr=2,width=760,onerror=redirect,format=auto/https%3A%2F%2Ffiles.gitbook.com%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FvjXMCrVxKM4rIxrP7AcN%252Fuploads%252F9sLNXFEbjxkUJltPY0nH%252FScreenshot%25202025-04-21%2520at%25208.18.46%25E2%2580%25AFAM.png%3Falt%3Dmedia%26token%3Dce27cce1-7b59-47de-a183-f8b6d5df2233)
