## Instructions
1. After logging into your instance, update the Application scope to _Animal Shelter Experience._
    
2. Within the **All** menu on the Unified Navigation header, navigate to **Animal Shelter**. This application contains the following tables:
    
    - **Animals**
        
    - **Events**
        
    - **Appointments**
        
    
3. Open UI Builder by navigating to **Now Experience Framework > UI Builder** within the **All** menu on the Unified Navigation header.
    
4. Within the UI Builder Home page, select the **Create** button in the top right corner of the page and choose **Experience**.
    
5. Within the _Create an experience_ modal, specify the following field values and select Create.
    
    - Name: **Animal Shelter** App shell UI: **Workspace App Shell** URL path: **animal-shelter** Landing path: **home**
        
    
6. Select **Open experience**. You will be directed to the Experience view where you can start creating pages.
